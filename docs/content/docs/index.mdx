---
title: NodeMailServer
description: A self-hosted mail stack that receives mail on port 25, sends it from port 587 and serves mailboxes over IMAP.
---

NodeMailServer started as a fun experiment and has grown into a small mail platform you run yourself. It receives mail for your domains, checks who sent it, accepts mail from your own apps and mail clients, and delivers it to the rest of the internet.

<Callout title="Under development" type="warn">
  Receiving and sending mail are implemented. Mailbox storage and IMAP are still being built, and some plugins are not connected to the mail pipeline yet. Each page says what is ready and what is not.
</Callout>

## What is in the box

| Part | Folder | Port | What it does |
|------|--------|------|--------------|
| Mail server (Node + TypeScript) | `server/` | 25 and 587 | Receives mail on 25 and checks it with DKIM, SPF and DMARC. Accepts authenticated mail on 587, signs it with DKIM and queues it for delivery. |
| Sending MTA (KumoMTA) | `outbound/` | 587 | Optional delivery engine with SMTP AUTH, per-domain rate limits, DKIM and delivery webhooks. |
| IMAP server (Go + Gluon) | `server/imap/` | 143 | Lets mail clients read mailboxes. Work in progress. |
| Documentation | `docs/` | 3000 | This site. |

## How mail flows

```
Receiving
  Internet ──25──▶ IncomingServer ──▶ DNS checks ──▶ DKIM / SPF / DMARC
                                      ──▶ ARC seal ──▶ PGP encryption ──▶ store

Sending
  Mail client or app ──587 + AUTH──▶ OutgoingServer ──▶ DKIM sign ──▶ outbound queue
                                      ──▶ recipient's MX server
                                      ──▶ or a relay such as KumoMTA
```
